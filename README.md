# Reforzamiento - TypeScript & Vite

> Proyecto de práctica para reforzar conceptos fundamentales de desarrollo web moderno antes de React

[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat-square&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Vite-646CFF?style=flat-square&logo=vite&logoColor=white)](https://vitejs.dev/)

## 🚀 Inicio Rápido

```bash
# Instalar dependencias
npm install

# Ejecutar servidor de desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar construcción
npm run preview
```

## 📝 Descripción

Proyecto educativo diseñado como ejercicio de reforzamiento para consolidar conocimientos fundamentales de TypeScript y herramientas de desarrollo modernas. Implementa una aplicación web interactiva con contador que demuestra las mejores prácticas antes de adentrarse en React.

## 🛠️ Tecnologías

- **TypeScript** - Tipado estático para JavaScript
- **Vite** - Herramienta de construcción rápida
- **HTML5/CSS3** - Estructura y estilos
- **ES Modules** - Sistema de módulos moderno

## 📂 Estructura del Proyecto

```
src/
├── main.ts          # Punto de entrada principal
├── counter.ts       # Lógica del contador
├── style.css        # Estilos de la aplicación
├── typescript.svg   # Logo de TypeScript
└── vite-env.d.ts   # Definiciones de tipos de Vite
```

## 🎯 Objetivos de Aprendizaje

- ✅ Dominar TypeScript y tipado estático
- ✅ Configurar y usar Vite como build tool
- ✅ Manipular el DOM con type safety
- ✅ Implementar arquitectura limpia y modular
- ✅ Preparar base para desarrollo con React
